This is Training.


A Puzzle game I created while doing my Game Dev Course

This game was quite an adventure, creating complex puzzles and trying to think about what would be tricky for the player
without being obvious is quite an experience, not knowing the experience level of the person playing your game while trying to gauge difficulty
was something new for me, I think I executed on it well.

Creating the puzzles was a fun task, coding the attachment of the keys to the doors to have them react when interacted with, the enemy lazer AI as well using triggers to activate the lazer but having the raycast to be blocked by a gameobject to allow for the player to overcome that challenge.

The Goal was to create a puzzle game with some Animations tied to the camera for a cut scene using keyframes to have the camera follow a streamlined path creating and immersing the player further yet showing them what is to come!

You must Complete your Training.
